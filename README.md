# Roll Siege

Armadillos disparados con un cañón de pólvora contra fortalezas de mapaches bandidos. Construye tu propia fortaleza (clanes Japón, Lejano Oeste, Azteca).

- Juego: `www/` (HTML5 canvas + planck.js), empaquetado con Capacitor para Android.
- Cada push a `main` compila el APK en GitHub Actions (pestaña Releases).
- Tests: `node tests/test_levels.js` (estabilidad) y `node tests/test_win.js` (se pueden ganar).
